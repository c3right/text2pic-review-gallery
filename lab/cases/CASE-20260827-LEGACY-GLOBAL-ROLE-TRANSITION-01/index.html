# 分块段 02 Prompt

生成一张 3:4 竖式静态配图。顶部放主标题“这不是清库存，是角色在变”。

标题下方采用上下两段结构。上方放一张横向大数据卡片，内部画出口车辆流向、大号数据锚点、上升趋势线和轻出口箭头，可带少量集装箱或港口发运信号。上方卡片中清楚放出“104.5 万辆”“7.9%”这两个数字。

下方放一张横向大卡片，画中国工厂与研发、制造、出口三类能力共同并列，配向外连接箭头和轻全球节点，把判断落到中国区角色升级。上方数据卡通过一条轻向下箭头或趋势延续线压向下方角色变化卡，形成先证据后判断的关系。

如使用地图，只用全球流向小示意，保持中国制造向海外出口语境，不要画成中国内销地图，不要做成抽象地球球体，不要只画一座工厂。

图中只允许出现这些文字：“这不是清库存，是角色在变”“104.5 万辆”“7.9%”。除这些文字外，不要新增任何说明性文字。不要水印，不要“AI生成”字样，不要品牌官方 logo，不要额外英文装饰。

整体视觉采用清晰、理性、模块边界明确、信息重点突出的 clean editorial illustration，flat illustration，light texture.

# 分块段 03 Prompt

生成一张 3:4 竖式静态配图。顶部放主标题“只做本地销售，已经跑不起来”。

标题下方采用左右对照加底部收束结构。左侧放一张竖向大卡片，标题写“自主品牌抬升”，内部画中国品牌销量柱状抬升图、车辆队列、上升箭头和份额圆环，可配“2093.6 万辆”“市占率69.5%”两个数字。不要做成股市图表页。

右侧放一张竖向大卡片，标题写“跨国车企在华产能利用率下滑”，内部画低利用率工厂与稀疏产线，配下滑折线、空工位、停滞产线信号，可配“掉到56%”数字。重点是跨国车企在中国工厂的利用率压力，不要误读成单纯销量下滑。不要画成废弃工厂灾难图。

最底部单独放一条横向结论条，写“只做本地销售，已经跑不起来”。左侧和右侧两张卡通过轻向下汇聚线压向底部结论条，让观众同时看到上升压力和空转压力最终指向同一个后果。

图中只允许出现这些文字：“只做本地销售，已经跑不起来”“自主品牌抬升”“跨国车企在华产能利用率下滑”“2093.6 万辆”“市占率69.5%”“掉到56%”。除这些文字外，不要新增任何说明性文字。不要水印，不要“AI生成”字样，不要品牌官方 logo，不要额外英文装饰。

整体视觉采用清晰、理性、对照强、底部收束明确的 clean editorial illustration，flat illustration，light texture.
