# 分块段 04 Prompt

生成一张 3:4 竖式静态配图。顶部放主标题“中国不只是低成本”。

标题下方自上而下放三张纵向大卡片，保持结构稳定、间距清楚。

第一张卡片标题写“供应链全”。卡片内部画多层供应链节点围绕一辆新能源车或电池总成，配零部件节点、短连线和产业协同信号，可带轻产业圈边界，可放“本土化率 95%”这句短文字。重点是中国供应链密度，不要只剩散点网络，没有制造对象。

第二张卡片标题写“反应快”。卡片内部画高效率产线上的车辆下线场景，配计时器、快速节奏产线和效率信号，可放“30 多秒下线一台车”这句短文字。不要画成夸张机械科幻图。

第三张卡片标题写“技术成熟”。卡片内部画工程师围绕本土技术底座与新产品草图协作，配研发桌面、模块化平台和优化信号，可放“研发周期缩短 30%”“成本结构优化 40%”这两句短文字。不要只画一块抽象芯片。

三张卡片按上中下顺序排列，用轻递进连接线保持同一能力链。如使用地图，只用中国产业圈示意，保持中国全球底座语境，不要用欧美本土制造地图替代中国语境。

图中只允许出现这些文字：“中国不只是低成本”“供应链全”“反应快”“技术成熟”“本土化率 95%”“30 多秒下线一台车”“研发周期缩短 30%”“成本结构优化 40%”。除这些文字外，不要新增任何说明性文字。不要水印，不要“AI生成”字样，不要品牌官方 logo，不要额外英文装饰。

整体视觉采用清晰、理性、结构稳定、卡片边界明确但不过硬的 clean editorial illustration，flat illustration，light texture.
