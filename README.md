# text2pic-review-gallery

Public GitHub Pages publication of the derived review gallery for the `w-text2pic` historical image corpus.

This repository contains **derived review assets only**:
- HTML pages
- previews
- thumbnails
- contact sheets
- metadata JSON
- gallery manifest

It intentionally does **not** contain:
- canonical original images
- DOCX source files
- the private `hotspot` repository
- conversation archive source materials
